Google Tasks & Calendar

How to get a Client ID (about 3 minutes)
  1. Open console.cloud.google.com and create (or pick) a project.
  2. APIs & Services → Library: enable Google Tasks API and Google Calendar API.
  3. OAuth consent screen: choose External, fill the app name, and add your Google account under Test users.
  4. Credentials → Create credentials → OAuth client ID → type Web application.
  5. Under Authorized JavaScript origins add:
  6. Copy the Client ID, paste it above and press Connect Google.

This page is opened as a file. Google sign-in only works when it's served from http://localhost or an https website.
